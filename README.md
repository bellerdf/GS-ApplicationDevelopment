# Meu Ponto SP - Global Solution FIAP

Aplicação web desenvolvida em HTML, CSS e JavaScript para a Global Solution de Application Development (Prof. Rodrigo Moraes). O app consome a **API Olho Vivo da SPTrans** em tempo real para ajudar cidadãos a consultarem paradas de ônibus e previsões de chegada em São Paulo.

## Funcionalidades
- Pesquisa de pontos de ônibus por nome ou endereço.
- Painel de previsão de chegada dos veículos em tempo real.
- Identificação de veículos acessíveis.
- Modo de alto contraste para acessibilidade visual.

## Como Executar
1. Clone o repositório.
2. Execute na Vercel para suporte a serverless functions.
